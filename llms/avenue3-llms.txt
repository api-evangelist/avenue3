# Avenue3

> Avenue3 Limited is a UK open data and openEHR technology consultancy based in Leeds. It
> sells strategy, discovery, architecture and engineering engagements to public sector and
> healthcare organisations. It is not an API provider: it publishes no developer portal, no
> API documentation and no machine-readable contract, and the APIs it builds are operated by
> its clients.

## API surface

Avenue3 publishes NO API. Verified 2026-09-02:

- No OpenAPI, Swagger, GraphQL, gRPC/Protobuf, WSDL or AsyncAPI contract on any Avenue3 host.
- No developer portal, API reference, quickstart, sandbox, pricing page or sign-up.
- No MCP server and no A2A agent card.
- /.well-known/security.txt, /openid-configuration, /oauth-authorization-server,
  /oauth-protected-resource, /api-catalog, /ai-plugin.json, /agent-card.json and /agent.json
  all return 404 on avenue3.com.
- No status page, changelog, CLI, embedded components or published rate limits.

The standard Avenue3 works in — openEHR — does define REST APIs, but those specifications are
published by openEHR International (https://specifications.openehr.org/), not by Avenue3, and
any deployed instance belongs to the client Avenue3 built it for.
